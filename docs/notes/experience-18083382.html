Experience

언리얼에서 게임 규칙은 대게 게임 모드에서 관리한다
예를들어 FPS게임에서 AOS게임으로 모드를 전환한다고 할 때 보통은 게임 모드를 변환한다.

하지만 언리얼엔진의 게임모드는 무겁다.
GameModeBase를 상속받아도 게임모드의 변경이 무겁다고 한다

그래서 라이라에서는 1개의 GameMode만 사용한다.

라이라에서는 모드를 변경하고싶을때 Experience라는 것을 변경함으로써 이를 실현시킨다.

Experience : 게임 모드를 대체하는 작은 게임모드

Experience는 UPrimaryDataAsset을 상속받아서 만든다.

아래는 유저가 처음 맞이할 Experience다

Experience와 연계해서 사용할 기본 요소들

라이라의 프로젝트 초기 흐름이다.
게임 초기에 게임모드가 어떤 Experience를 로딩할지 결정하는 함수
HandleMatchAssignmentIfNotExpectingOne 를 호출해야하는데, InitGame당시에는
ExperienceLoad를 맡을 ExperienceManagerComponent가 생성되어있지 않아 로딩된 Experience들이 없다.
그렇다고해서 뭐 델리게이트쓰거나 시점을 어렵게 잡기보다는
다음 프레임 시작전에 ExperienceManagerComponent를 가지는 GameState를 스폰을 하고
SetTimerForNextTick으로 다음프레임에 자동으로 해당 함수가 호출되도록 한다.

프로젝트 첫 프레임에는 ExperienceLoad를 맡을 ExperienceManagerComponent가 생성되어있지 않음
아래 코드 확인

void ALCGameModeBase::InitGame(const FString& MapName, const FString& Options, FString& ErrorMessage)
{
 Super::InitGame(MapName, Options, ErrorMessage);
 // 한 프레임 뒤로 미루는 이유는
 // Experience의 로딩은 ExperienceManagerComponent에서 맡는데 Init 게임 시점에서는 해당 컴포넌트를 가지는 액터가 스폰되어있지 않다.
 // 그래서 스폰이후로 시점을 잡기위해 타이머로 한 틱 미룬다.
 GetWorld()->GetTimerManager().SetTimerForNextTick(this, &ThisClass::HandleMatchAssignmentIfNotExpectingOne);
 
}

ExperienceLoad를 맡을 ExperienceManagerComponent 클래스이다.

enum class ELCExperienceLoadState
{
 Unloaded,Loading,Loaded,Deactivating,
};
DECLARE_MULTICAST_DELEGATE_OneParam(FOnLCExperienceLoaded, const ULCExperienceDefinition*);
/**
ULCExperienceManagerComponent
- 말 그대로, 해당 컴포넌트는 GameState를 Owner로 가지면서 Experience의 상태 정보를 가지고 있는 컴포넌트이다.
- 뿐만 아니라, Manager라는 단어가 포함되어 있듯 Experience 로딩 상태 업데이트 및 이벤트 관리를 맡는다.
 
 */
UCLASS()
class LYRACLONE_API ULCExperienceManagerComponent : public UGameStateComponent
{
 GENERATED_BODY()
public:
 bool IsExperienceLoaded() const { return (LoadState == ELCExperienceLoadState::Loaded) && (CurrentExperience != nullptr); }
 // OnExperienceLoaded에 바인딩하거나 Experience로딩이 완료되었다면 즉시 호출 
 void CallorRegister_OnExperienceLoaded(FOnLCExperienceLoaded::FDelegate&& Delegate);
public:
 UPROPERTY()
 TObjectPtr<class ULCExperienceDefinition> CurrentExperience;
 // Experience상태 모니터링
 ELCExperienceLoadState LoadState = ELCExperienceLoadState::Unloaded;
 // Experience 로딩이 완료된 이후 Broadcasting Delegate
 FOnLCExperienceLoaded OnExperienceLoaded; 
};

여기까지가 Experience로딩 과정의 끝이다.

Experience의 로딩 과정정리
  1. GameMode::InitGame에서 다음틱에 GameState의 ExperienceLoadedComponent가 HandleMatchAssignmentIfNotExpectingOne 함수를 호출하도록 설정
  2. GameMode::InitGameState에서 ExperienceManagerComponent 가 로딩을 마치면 ALCGameModeBase::OnExperienceLoaded 를 호출하도록 ExperienceManagerComponent의 델리게이트 구독
  3. PlayerController가 Spawn되고 나서 PlayerState Spawn
  4. PlayerState가 Spawn되면서 ALCPlayerState::PostInitializeComponents 가 호출되고, ExperienceManagerComponent 가 로딩을 마치면 ALCPlayerState::OnExperienceLoaded 를 호출하도록 ExperienceManagerComponent의 델리게이트 구독
  5. PlayActor가 생성될 차례지만 ALCGameModeBase::HandleStartingNewPlayer_Implementation 에서 IsExperienceLoaded 함수로 Experience가 로딩이 되지 않았으면 PlayActor생성을 막음
  6. 엔진틱 다음틱으로 넘어감
  7. ExperienceLoadedComponent가HandleMatchAssignmentIfNotExpectingOne 함수 호출
  8. 우선순위 따라서 로드할 ExperienceId고르고 ExperienceLoadedComponent에 해당 Id전달
  9. ExperienceId를 사용해 ExperienceDefinition에셋 로드 및 클래스 얻음
  10. StartExperienceLoad 를 통해 Experience로드 시작
  11. StartExperienceLoad 함수내에서 에셋 번들 비동기 로드 시작 및 로드 완료 이벤트로 OnExperienceLoadComplete 함수 구독
  12. 위의 ALCGameModeBase::OnExperienceLoaded (2번)와 ALCPlayerState::OnExperienceLoaded (4번)가 구독중인 OnExperienceLoaded 델리게이트 브로드 캐스팅

Experience 로딩 과정정리
  1. AOWGameMode::InitGame에서 다음 틱에 HandleMatchAssignmentIfNotExpectingOne 예약
  2. URL Option의 Experience 값을 우선 확인하고, 없으면 기본 Experience 사용
  3. AOWGameMode::OnMatchAssignmentGiven이 UOWExperienceManagerComponent::ServerSetCurrentExperience 호출
  4. Experience PrimaryAsset을 로드하고 CurrentExperience 설정
  5. StartExperienceLoad에서 Experience와 ActionSet의 Bundle을 Client/Server NetMode에 맞게 로드
  6. OnExperienceLoadComplete에서 Experience/ActionSet의 GameFeaturesToEnable을 모아 GameFeature Plugin 로드 및 활성화
  7. OnExperienceFullLoadCompleted에서 Experience Actions와 ActionSet Actions를 실행
