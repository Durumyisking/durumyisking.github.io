### <b>구조체</b>

구조체는 사용자 정의 자료형임

struct Pos<br />\{<br />  int x;<br />  int y;<br />\}; 으로 선언 가능

접근법 : Pos.x, Pos.y로 접근

구조체에도 생성자 소멸자가 있다!? (틀딱 컴파일러에는 디폴트생성소멸자 없음)

```c++
struct Node
{
	int Data;
	Node()
	{
		Data = 10;
	}
}
```
