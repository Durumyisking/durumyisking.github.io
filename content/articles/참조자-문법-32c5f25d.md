<b>레퍼런스</b>

<b>참조연산자 &</b>

<b>선언법 </b>: int& num2 = num; <b>⇒</b> num의 값을 참조하는 변수 num2를 만들겠다

포인터보다 <b><span>더 편하게</span></b> 사용할수 있음

```c++
int num = 10;
int& num2 = num; // num2로 num참조

// 반드시 선언시에 참조할대상 지정
int& num3; // 안됨

// 참조대상 변경 불가능
num2 = numE; // 안됨
```
