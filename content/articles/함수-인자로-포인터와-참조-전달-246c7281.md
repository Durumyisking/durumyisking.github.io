Pointer와 Reference의 메모리 특성에 의해 일어나는 차이에 대해 알아보자\~

---

<b>CallbyPointer </b>

포인터를 값으로 넘기면 매개변수에는 포인터 값이 복사된다. 포인터가 가리키는 객체는 복사되지 않는다.

```cpp
void AddOneByPointer(int* value)
{
	if (value != nullptr)
	{
		++*value;
	}
}
```

<b>CallbyReference</b>

참조 매개변수는 호출자가 넘긴 객체의 별칭으로 동작한다.

```cpp
void AddOneByReference(int& value)
{
	++value;
}
```

둘 다 위 예제에서 원본 `int`를 직접 바꾼다. 대상을 반드시 받아야 하는 인터페이스에는 참조가 자연스럽고, 대상 없음까지 표현해야 하면 널 포인터를 받을 수 있다.
