가상함수를 사용하지 않으면

```c++
class parent
{
void print();
}

class child : public parent
{
void print();
}
```

해당 상황에서 parent type 포인터에 child의 포인터를 받아서 print를 사용했을때

자식의 print가 아니라 부모의 print를 사용하게 된다.

우선 이를 정확히 이해하려면 동적 바인딩과 정적 바인딩에 대해 알고있어야한다.

<b>정적 바인딩</b>

- 일반적으로 함수, 변수 선언하는 경우
- 컴파일 단계에서 바인딩된다.
- 런타임 중에 그 함수를 사용할 때 해당 바인딩된 공간을 참조한다.

<b>동적 바인딩</b>

- virtual 붙여서 함수 선언하는 경우
- 함수를 실행할 때 바인딩된다.
- 부모의 가상함수들을 가지고 있는 가상함수 테이블을 만든다.
- 자식이 재정의한 함수들이 있으면 해당 함수의 포인터로 가상함수테이블을 수정한다.

이런 동작으로 자식의 함수를 사용하게 된다.

- <b>그럼 왜 써요??</b>
  - 위에 명시해놓은게 써놓는 이유이다.
  - 함수의 오버라이딩은 virtual을 선언하지 않아도 할 수 있다.
  - 하지만 가상함수로 만들어 놓으면 자식에서 함수를 재정의 하지 않았을 때
    부모의 함수를 사용할 수 있다는 것이다

- 가상함수를 왜 써요?
  <aside class="callout">

  가상함수는 다형성 개념을 구현하기 위해서 사용됩니다.<br />자식이 아무리 많아도 슈퍼클래스만 사용하여 자식객체의 함수들을 부를수 있게 할 수 있습니다.<br /><br />가상함수를 사용하지 않으면 함수가 정적 바인딩 되기 때문에<br />자료형이 가르키는 기준으로 함수를 호출합니다.<br /><br />하지만 가상함수를 사용하면 함수가 호출될 때 바인딩되어<br />포인터가 가리키는 기준으로 함수를 호출합니다.

  </aside>

- 가상함수 동작 원리가 어떻게 돼요?
  <aside class="callout">

  일반적인 함수는 컴파일단계에서 사용할 함수를 바인딩한다.<br />이럼 부모 자료형으로 만든 객체는 당연히 부모 함수를 찾아가게 된다.<br /><br />가상함수로 선언하게 되면 컴파일 단계에서 만들어지는 가상함수 테이블에 함수 포인터가 등록이 된다. (가지고 있지 않으면 superclass의 가상함수를 등록)<br /><br />가상함수는 함수 코드를 실행할 때 가상함수 테이블에 접근해 해당 바인딩이 된다.<br />

  </aside>
