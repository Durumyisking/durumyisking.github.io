<b>컴퓨터의 데이터 저장방식</b>

-데이터를 2진수로 저장함

-자료형을 선언하면 메모리 한 공간에 선언한 데이터가 저장됨

-우리가 선언하는 변수의 이름 = 메모리에 데이터가 저장되는 위치

-메모리에 데이터들을 적재할수 있게 해주는게 운영체제(OS)

-컴퓨터가 프로그램을 종료하면 메모리의 링크를 끊어줌 (즉 끊어진 메모리에는 데이터가 잔류함)

### <b>변수 선언</b>

<b>규칙</b>

- 이미 예약되어있는 키워드는 식별자(이름)이 될 수가 없다.
- 대소문자는 구별이 된다.
- 이름은 대소문자, 숫자, 및 문자로만 구성이 가능하다
- 대소문자와 함께 \_는 이름으로 사용이 가능하다.

<b>기타</b>

- 맨 앞에 unsigned를 붙이면 양수로만 표현 가능 (소수는 예외)
- 맨 앞에 const를 붙이면 변수가 아닌 상수로 선언 가능
- 자료형 선언후 초기화를 시켜주지 않으면 쓰레기값이 들어감
- 초기화 = 변수를 선언과 동시에 값 대입 ( int i = 0)
- 대입 = 변수 선언 후에 값 대입

### <b><span>8bit → 1byte</span></b>

- <b>int </b>: <b>4byte</b>(<b>32bit</b>) 최대 2의 32승의 <b>정수</b>를 저장 가능

<b>메모리 영역</b>

- 코드영역 : 우리가 입력한 코드들이 들어감
- 데이터영역 : 전역변수
- 스택(stack) : 지역변수
- 힙(heap) : 동적 메모리

<b>지역변수</b>

<b>코드블럭 내에서 선언한 변수는 지역변수</b>라고 불리며

<b>코드블럭 외에서 사용이 </b><b><span>불가능</span></b>하고 코드블럭을 <b>탈출하면 메모리에서 </b><b><span>해제</span></b>된다.

<b>전역변수</b>

- 코드블럭 외에 선언함
- 모든 파일에서 사용이 가능
- 메모리의 데이터 영역을 차지

<b>선생님 그럼 전부다 전역변수로 만들면 편하지 않나요?</b>

전역변수는 선언후 프로그램 종료 전까지 <span>사라지지 않음</span> <b>⇒</b> <b><span>X</span></b>메모리를 계속 잡아먹음<b><span>X</span></b>

<b>static 변수</b>

- 데이터영역 사용

소멸자 private

<b>extern변수</b>

- 변수를 전역변수에 <b>extern</b>키워드를 붙여서 선언하면
- 프로젝트내 모든 파일에서 해당 변수를 사용가능하다.

<b>Lvalue / Rvalue</b>

<b>Lvalue </b>는 왼쪽에 있는 값 (변할수 있는 값)

<b>Rvalue </b>는 오른쪽에 있는 값 (상수)
