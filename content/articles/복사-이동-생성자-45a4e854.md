<b>복사생성자</b>

<b>아래는 가장 일반적인 형태의 복사 생성자이다.</b>

```c++
T(const T& a);
```

<details>
<summary><b>예시</b> <b>코드</b></summary>

```c++
#include <string.h>
#include <iostream>

class Photon_Cannon {
  int hp, shield;
  int coord_x, coord_y;
  int damage;

 public:
  Photon_Cannon(int x, int y);
  Photon_Cannon(const Photon_Cannon& pc);

  void show_status();
};
Photon_Cannon::Photon_Cannon(const Photon_Cannon& pc) {
  std::cout << "복사 생성자 호출 !" << std::endl;
  hp = pc.hp;
  shield = pc.shield;
  coord_x = pc.coord_x;
  coord_y = pc.coord_y;
  damage = pc.damage;
}
Photon_Cannon::Photon_Cannon(int x, int y) {
  std::cout << "생성자 호출 !" << std::endl;
  hp = shield = 100;
  coord_x = x;
  coord_y = y;
  damage = 20;
}
void Photon_Cannon::show_status() {
  std::cout << "Photon Cannon " << std::endl;
  std::cout << " Location : ( " << coord_x << " , " << coord_y << " ) "
            << std::endl;
  std::cout << " HP : " << hp << std::endl;
}
int main() {
  Photon_Cannon pc1(3, 3);
  Photon_Cannon pc2(pc1);
  Photon_Cannon pc3 = pc2;

  pc1.show_status();
  pc2.show_status();
}
```

</details>

디폴트 복사생성자는 인자로 들어온 T타입의 인스턴스를 [얕은복사](%EC%96%95%EC%9D%80-%EB%B3%B5%EC%82%AC%EC%99%80-%EA%B9%8A%EC%9D%80-%EB%B3%B5%EC%82%AC-8b00fd8e.md)해서 새로운 인스턴스를 생성한다.

복사생성중에 원본을 수정할 수 있는 실수를 방지하기 위해 const &를 사용한다.

<a href="%EB%B3%B5%EC%82%AC-%EC%83%9D%EB%9E%B5-aeb0f99e.md">복사생략</a> 

<b>L/R Value</b>

- <b>LValue</b>
  주소값을 취할 수 있는 값

  식의 왼쪽/오른쪽 아무데나 존재 할 수 있다.

- <b>RValue</b>
  주소값을 취할 수 없는 값

  식의 오른쪽에만 존재하여야 한다.

<b>LValue Reference</b>

```c++
int a;         // a 는 좌측값
int& l_a = a;  // l_a 는 좌측값 레퍼런스

int& r_b = 3;  // 3 은 우측값. 따라서 오류
```

```c++
int& func1(int& a) { return a; }
int func2(int b) { return b; }

int main() {
  int a = 3;
  func1(a) = 4;
  std::cout << &func1(a) << std::endl;

  int b = 2;
  a = func2(b);               // 가능
  func2(b) = 5;               // 오류 1
  std::cout << &func2(b) << std::endl;  // 오류 2
}
```

func1은 lValue를 return하고 func2는 rValue를 return하기 때문에 해당 현상이 생긴다.
