### <b>문자열 상수 (리터럴)</b>

- L”Hello World”처럼 프로그램 소스 안에 포함된 문자열
- 리터럴이란 소스코드에 고정된값들을 의미한다
  - (문자열, 숫자, 부동소수점 등등)

문자열 상수는 컴파일시 <b><span>DATA 영역의 Text Segment</span></b>라는 특별한 공간에 저장된다.

<b>Text Segment는 read only data영역이다.</b>

문자열 상수는 우리가 사용하는 일반 rValue(상수) (1,2,3,4)처럼

우리가 1 = iData; 이렇게 할 수 없듯

“Hello World” = strName; 이런 시도를 하면 운영체제에서 막는다.

```javascript
char* str = "Hello world"; // 텍스트 세그먼트에 Hello world\0 이라는 문자열 저장
													 // 데이터 세그먼트(힙 스택)에 Hello world의 H부분의 
													 // 주소를 str이라는 변수에 저장

str = "Goodbye world"; // 텍스트 세그먼트에 Goodbye world\0 이라는 문자열 저장
											 // str이 G가 있는 부분의 주소를 가리키게함
```
