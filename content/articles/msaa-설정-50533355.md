먼저 사용하고 있는 gpu가 MSAA 사용이 가능한지 확인한다.

```c++
device->CheckMultisampleQualityLevels(DXGI_FORMAT_R8G8B8A8_UNORM, 4,
                                          &numQualityLevels);
// 사용이 불가능하면 numQualityLevels에 0이 반환된다.
```

swapChain 생성시 SampleDesc의 Count와 Quailty를 설정한다.

```c++
DXGI_SWAP_CHAIN_DESC sd;
if (numQualityLevels > 0) {
      sd.SampleDesc.Count = 4; // how many multisamples
      sd.SampleDesc.Quality = numQualityLevels - 1;
  } else {
      sd.SampleDesc.Count = 1; // how many multisamples
      sd.SampleDesc.Quality = 0;
  }
```

DSV를 생성 할 때도 마찬가지로 Count와 Quailty를 설정한다. 

```c++
D3D11_TEXTURE2D_DESC depthStencilBufferDesc;
if (numQualityLevels > 0) {
        depthStencilBufferDesc.SampleDesc.Count = 8; // how many multisamples
        depthStencilBufferDesc.SampleDesc.Quality = numQualityLevels - 1;
    } else {
        depthStencilBufferDesc.SampleDesc.Count = 1; // how many multisamples
        depthStencilBufferDesc.SampleDesc.Quality = 0;
    }
```

MSAA를 사용할 경우 backBuffer가 Texture2D가 아니라 Texture2DMS가 되므로

우리가 쉐이더에서 Texture2D로 하는 것들을 하려면 (ex - postprocess)

Texture2DMS를 Texture2D로 변환해야한다.

```c++
ComPtr<ID3D11Texture2D> backBuffer;
    m_swapChain->GetBuffer(0, IID_PPV_ARGS(backBuffer.GetAddressOf()));
    m_context->ResolveSubresource(m_tempTexture.Get(), 0, backBuffer.Get(), 0,
                                  DXGI_FORMAT_R8G8B8A8_UNORM);
```
