컴퓨터 성능이 좋을수록 당연하게도 연산이 더 빠르다.

즉 우리가 while문에서 update and render을 할때 컴 성능이 좋을수록 동일 시간 대비 더 자주함

ex) 이동을 할 때 똥컴에서는 1초에 update을 10번수행 슈퍼컴에서는 1초에 100번 수행한다는 것

그래서 우리는<span> </span><b><span>안좋은 컴</span></b>에서 돌리나 <b><span>좋은 컴</span></b>에서 <b><span>전부 똑같이 연산</span></b>되도록 처리해야함

이를 <b>프레임 동기화</b>라고 한다.

```c++
QueryPerformanceCounter(); // cpu부팅후 현재까지의 진동수를 받아온다. (시간의 흐름을 의미)

QueryPerformanceFrequency(); // 내 cpu의 고유 진동수를 받아온다.

현재update - 이전update진동수 = 1프레임당 걸리는 걸리는 진동수
(현재update - 이전update진동수) / 고유진동수 = DeltaTime
// DeltaTime : 한 프레임당 걸리는 시간 (당연하게 컴퓨터가 느리면 델타타임이 더 큼)
이렇게 나온 DeltaTime을 시간이 필요한 모든 행동에 곱해준다.
```

<br />예를들어 컴퓨터 A와 A보다 2배빠른 B가 있다고 할 때

A의 DT는 B의 2배이기 때문에

B가 10번 update동안 10까지 움직일때

A는 5번 update만으로 10까지 움직이게 된다.

따라서 B는 1번 update때마다 움직임이 이고

A는 B의 절반만큼만 보이게 된다.
