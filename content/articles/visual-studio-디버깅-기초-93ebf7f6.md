<ul>
<li>
디버깅 때는 프로그램 생성 안됨 ⇒ 빌드해야 생성
</li>
<li>
프로젝트 생성시 솔루션 탭 (가장 큰 틀)
</li>
<li>
빌드시 컴파일러가 소스코드를 이진법으로 해석 
</li>
<li>
우리가 사용하는 비주얼스튜디오 이클립스 안드로이드 등등을 IDE

(통합 개발환경 프로그램이라고 부름)
</li>
<li>
#include 를 전처리기라고 부름 - 프로그램 실행전에 실행 (빌드단계 이전)
</li>
</ul>

- 비주얼스튜디오 디버깅
  - F10 - 프로그램 처음부터 한 줄씩 실행
  - ctrl + F10 - 커서 위치까지 실행후 멈춤 한 줄씩 실행
  - F5 - 중단점까지 실행후 멈춤
  - F9 - 커서 위치에 중단점
  - // - 한줄 주석, /\*code\*/ - 범위 주석
  - ctrl + k + c - 한번에 주석처리
  - ctrl + k + u - 주석 한번에 해제

- 조사식 사용법
  이름에 원하는 변수명 넣으면 현재 상태 출력

- 조건식 사용법
  - 특정 변수나 함수에 조건을걸어 그 조건이 될때 중단 걸림
