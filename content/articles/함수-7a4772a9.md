### <b>함수</b>

우리가 코드를 반복해서 사용할때 편하게 해줌

- 선언법 : 반환자료형 함수명 (매개변수) \{\}
- 접근법 : 함수명(매개변수);
- 매개변수에 값을 넘겨줄때 값을 복사해서 넘겨준다. (얕은복사)
- 얕은복사(call by value) : 복사하는 원본의 값을 해치지 않고 복사
- 깊은복사(call by reference) : 값을 복사하고 원본의 값을 참조

<b>함수 오버로딩</b>

이름이 같은 함수여도 반환값, 매개변수가 다르면 사용이 가능하다.

<b>return 키워드</b>

코드블럭을 탈출하며 return 뒤에 적힌 값을 반환한다.

---

```c++
int result = a+b // 1

return result // 2
```

이 1번 2번 친구는 같은코드임

return a+b

<b>하지만 위 코드는 4바이트를 추가로 사용</b>

<b>하지만 너무 작은값이고 디버깅에서보는 이점이 훨씬 크기 때문에 값을 받아서 return해주는게 좋음</b>

---

```c++
int add(int _a, int _b)
{
	int result = _a + _b;
	return result;
}
```

\_a, \_b, result만있어서 <b>12바이트</b> 같지만<br /> 사실 <b>스택의</b> <b>temp에 결과값이 저장</b>되고<b> </b>그 값을 main으로 넘겨주기때문에<br /><b>16바이트</b>가 사용된다.

<b>템플릿</b>

동일한 역할의 함수를 다양한 자료형으로 사용하고 싶을 때 사용

<b>템플릿 함수</b>

```c++
// 여기서 T는 자료형 type
template <typename T>
T add(T a, T b)
{
	return a + b;
}

빌드단계에서 위의 코드가 사라지고 아래 주석에 있는 코드가 생성
/*
	float add(float a, float b)
	{
		return a + b;
	}
	
	int add(int a, int b)
	{
		return a + b;
	}
*/

int main()
{	
	char ch = static_cast<char>(65); // 우리가 사용하는 static_cast도 <>안에 T가 들어가있음

	// add<T>(매개인자)
	float	fSum = add<float>(3.0f, 0.14159f); // add를 float버전으로 사용
	int		iSum = add<int>(5, 5);             // add를 int버전으로 사용

	return 0;

}
```
