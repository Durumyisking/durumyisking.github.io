### <b>문자</b>

<b>아스키코드 </b>= 컴퓨터는 숫자를 모르기때문에 글자와 숫자를 매칭시켜서 숫자를 문자로 인식하게 함

c++은 기본적으로 <b>멀티바이트</b>로 되어있음

<b>멀티바이트</b> : 1바이트와 2바이트를 혼용

ex) char ch\[256\] = “abc한글”; 을 출력하면 출력이 잘됨

 “ “안에 들어가는걸 literal이라고 부름 (RValue)

2바이트 문자 wchar\_t를 사용

ex) wchar\_t wc = L’○’; 앞에 L을 붙여서 사용

### <b>문자열</b>

우리가 숫자 여러개를 int arr\[10\] 이렇게 선언하듯<br />문자가 여러개 붙은 문자열은 

char str\[256\] = \{'A', 'B', 'C'\}; 이렇게 선언<br />그런데 번거로우니까<br /><b>char str\[6\] = "Hello";  </b>이렇게 선언한다.

<br />근데 Hello는 5글자인데 왜 크기를 6으로 선언하나요?<br />마지막에 문자열의 끝을 날리는 <b><span>'\\0'(null) 문자를 포함</span></b>하기 때문<br />따라서 <b>char str\[6\] =\{'h', 'e', 'l', 'l', 'o', '\\0'\};</b>랑 같음

<b>우리가 문자열 사이에 문자를 넣을때</b>

1. 문자를 넣을 인덱스부터 \\0문자 전까지의 문자열 따로 저장
2. input + 1번부터에 따로 저장했던 문자열저장
