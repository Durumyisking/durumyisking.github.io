### <b>연산자 오버로딩</b>

우리가 기본 자료형 연산 외에도 연산자(+, -, \*, /등등) 가 존재하지 않는 자료형의

 연산을 좀 더 편하게 하기위해 연산자를 이름으로 함수를 만들어주는것

```c++
class Vector2
{
public:
	int ix;
	int iy;

// 연산자 오버로딩
public:
	// 반환형 operator 연산자 (연산 상대)
	Vector2 operator + (Vector2 _vOther)
	{
		Vector2 ret;
		ret.ix = ix + _vOther.ix;
		ret.iy = iy + _vOther.iy;

		return ret;
	}

// 전위 후위 나누기
	// 후위
	Vector2 operator ++(int) // 매개인자로 int 넣으면 후위
	{
		Vector2 ret;
		ret.ix = ix;
		ret.ix = iy;

		++ix;
		++iy;

		return ret;
	}

	// 전위
	Vector2& operator ++() // 전위연산은 반드시 참조로 받아야함
	{
		ix += 1;
		iy += 1;

		return *this;
	}

}

int main()
{
	Vector2 vec1 = { 5, 5 };
	Vector2 vec2 = { 15, 15 };
	Vector2 vecResult = {};
	vecResult = vec1 + vec2; // operator를 만들어줬기 때문에 사용 가능
	vec1++;
	++vec2; // 다 가능
}
```
