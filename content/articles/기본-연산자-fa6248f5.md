<b>증감연산자</b>

변수 앞뒤에 <b>++ —</b> 를 붙여서 사용

++num → 이 행에서 num에 1 추가

num— → 이 행을 마치고 num 1감소

<b>삼항연산자</b>

두 조건을 한줄에 비교할때 사용

( int ret = (mod > 0 ? <b><span>1</span></b> : <b><span>-1</span></b>); )

? 앞의 조건이 참이면 <b><span>좌측값</span></b><span> </span>return 거짓이면 <b><span>우측값</span></b><span> </span>return

<b>비트연산자</b>

<b>& : AND</b> → 둘 다 참이면 참

<b>\| : OR </b>→ 둘 중 하나만 참이면 참

<b>\^ : XOR</b> → 두 비트가 다르면 참

암호화에 자주 사용

데이터를 고유 key비트와 XOR연산해서 암호화를 해둠

따라서 key비트를 알면 암호화가 되어있는 데이터와 연산해서 원본데이터 획득 가능

<b>\~ : NOT </b>→ 비트 반전

<b>\<\< >> : SHIFT</b> → 비트를 왼쪽 오른쪽으로 한칸씩 밀어냄
