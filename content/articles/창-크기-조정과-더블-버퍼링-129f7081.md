1. 윈도우의 크기는 TopBar, MenuBar의 크기도 고려한다4-
   - RECT객체를 하나 만들어 window 해상도를 받는다.
   - AdjustWindowRect 함수를 사용해서 현재 윈도우 크기를 조정한다.
   - SetWindowPos를 이용해 윈도우 렌더링 위치를 변경한다.

```c++
// 현재 클라이언트 영역
RECT rt = { 0,0,m_vResolution.x, m_vResolution.y };
// 클라이언트 영역이 윈도우 크기가 되게 함
AdjustWindowRect(&rt, WS_OVERLAPPEDWINDOW, _bMenu);
// 윈도우 위치 설정
SetWindowPos(m_hWnd, nullptr, 100, 100, rt.right - rt.left , rt.bottom - rt.top, 0);
```

2. 화면 클리어를 할 때 모든 화면을 지웠다가 다시 그리면 화면이 깜빡이게 보일수 있다.
3. 잔상이 남을수 있다.
   - 이동할때 이전위치와 현재위치의 겹치는 부분에서 잔상이 발생한다
   - 이를 해결하는것 ⇒ 더블 버퍼링

   <ol type="a">
   <li>
   <b>더블 버퍼링</b>

   - MainDC와 SubDC를 둔다.
   - 다음프레임에서 렌더링 할 것들을 SubDC에 그린다
   - 다음프레임에서는 SubDC를 렌더링한다.
   - SubDC를 렌더링 한 프레임에서는 다시 MainDC를 SubDC로 둔다
   - 무환ㅋ반ㅋ복한다.
   </li>
   </ol>
