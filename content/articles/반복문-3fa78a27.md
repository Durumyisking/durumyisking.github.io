### <b>반복문</b>

<b>for문 - 조건을 충족하면 탈출</b>

```c++
for(**x = 1**; **조건**; **증감**)

{}
```

<b>while문 - 조건을 충족하면 무한 반복</b>

```c++
while(**조건**)

{}
```

<b>do - while문 - 조건을 만족하지 않아도 한 번 실행</b>

```c++
do
{} while (조건);
```

<b>향상된 for문 - 배열을 0부터 순차적으로 순회하며 순회할때마다 indexValue에 배열인덱스에 해당하는값을 전달해줌</b>

<b>for(자료형 indexValue : 배열) ⇒ for(type var: iterate)</b>

여기서 <b>iterate</b>는 순환(iterable)이 가능한 자료구조

<b>자료구조 내부 전체를 순차적으로 순환하면 걸리는 시간복잡도는 O(n)이다.</b>

Array는 값을 얻을때 인덱스로 접근하여 <b>O(1)</b>의 시간복잡도가 들지만

LinkedList는 get(index) 함수로 값을 얻을때마다 0부터 index까지 순회함 이는 <b>O(n\^2)</b>로

최악의 시간복잡도임 

따라서 우리는 <b>반복자(iterator)</b>를 사용하여  내부를 순회함

<b>Iterator : </b>iterable 자료구조는 순회하는데 도움을 주는 Iterator라는 인터페이스를 가지고 있음

iterator을 사용하면 index - 1 요소에 접근한 후 n번째 요소에 접근을 시도하기 때문에

시간복잡도가 <b>O(n)</b>임

그래서 LinkedList 값 순회할때는 향상된 포문이나 iterator을 꼭 쓰자

<b>break 키워드</b>

현재 코드블럭의 가장 최하위의 반복문을 탈출

<b>continue 키워드</b>

반복문의 남은 코드를 스킵하고 다음 반복으로 넘어감
